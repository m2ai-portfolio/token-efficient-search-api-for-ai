│ LOGGING MODES                                                                │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. DEFAULT MODE (Normal)                                                    │
│     Level: WARNING                                                           │
│     Output: Only warnings and errors to stderr                              │
│     Format: Simple - "WARNING: message"                                     │
│     Use case: Production deployment                                         │
│                                                                              │
│  2. VERBOSE MODE (--verbose)                                                 │
│     Level: DEBUG                                                             │
│     Output: All debug, info, warning, error messages                        │
│     Format: Detailed - timestamp, module, function, level, message          │
│     Use case: Development and troubleshooting                               │
│                                                                              │
│  3. QUIET MODE (--quiet)                                                     │
│     Level: ERROR                                                             │
│     Output: Only errors to stderr                                           │
│     Format: Simple - "ERROR: message"                                       │
│     Use case: Automation and scripts                                        │
│                                                                              │
│  4. LOG FILE (--log-file /path/to/file.log)                                 │
│     Level: DEBUG (always)                                                    │
│     Output: All debug messages to file                                      │
│     Format: Detailed - full context for offline analysis                    │
│     Use case: Production debugging, audit trails                            │
│                                                                              │
│  5. DEBUG ENV VAR (DEBUG=true)                                               │
│     Level: DEBUG                                                             │
│     Output: Enables debug logging without CLI flags                         │
│     Values: true, 1, yes (case-insensitive)                                 │
│     Use case: Container environments, systemd services                      │
